# Camera-Ready Checklist (ICML 2026 Baseline Version — Please Verify for the Target Year)

Copy into `.icml/camera_ready.md` and check off items only after verifying them (not when "mostly done").

## Timeline
- [ ] Camera-ready deadline and AoE time recorded (2026: May 28, 11:59pm AoE)
- [ ] In-person presentation questionnaire submitted (2026: before May 11) — author
- [ ] At least one author completed registration (in-person attendees select Conference option; paper-only select Conference or Virtual Pass) — author

## Content
- [ ] Every item in `promises.md` is in the paper and exactly matches the rebuttal
- [ ] Main body ≤ 9 pages; extra space used for responding to reviewer feedback, not for new claims
- [ ] Core content unchanged compared to the reviewed version (compare PDF/abstract)
- [ ] Conflict of Interest Disclosure: authors asked; added as the last paragraph of the introduction if applicable; otherwise omitted
- [ ] Impact Statement included (main conference papers), unnumbered, before references
- [ ] Acknowledgments added (unnumbered, before references), wording approved by authors
- [ ] Limitations still accurate after revisions

## Authors & First Page
- [ ] `\usepackage[accepted]{icml20XX}`
- [ ] Names, order, and affiliations match OpenReview profiles; no additions/deletions
- [ ] Equal-contribution marks and `\printAffiliationsAndNotice{...}` render correctly
- [ ] Corresponding author and email
- [ ] Short title appropriate (use `\icmltitlerunning{}` if needed)
- [ ] Title changes (if any) are minor or approved by PCs

## References
- [ ] Reference Correctness Check items from the OpenReview decision fixed
- [ ] arXiv citations replaced with published versions where possible
- [ ] Case protected; names and conference names updated; no duplicates
- [ ] No `??` / `(?)`

## Formatting
- [ ] US Letter; official style unmodified; no spacing hacks
- [ ] PDF ≤ 20 MB; appendix included in the same PDF (no camera-ready supplementary material)
- [ ] Title/headings: major words capitalized, not all-caps
- [ ] Abstract: one paragraph, about 4–6 sentences
- [ ] Citation font size equals body font size
- [ ] Figures use vector graphics; color palette accessible; language inclusive
- [ ] `check_submission.py --mode camera-ready` reports no ERROR
- [ ] ICML paper checker passed; 5-letter code recorded — author

## Code & Data
- [ ] Public archived repository; link in the paper; OpenReview "code url" field filled
- [ ] Repository cleaned (no `.icml/` notes, secrets, internal paths); includes license; includes README

## OpenReview Forms — Author Submission
- [ ] Title and abstract text exactly match the PDF (no custom macros; TeX accents)
- [ ] Lay summary (2026: ≤ 10 sentences / 200 words)
- [ ] Camera-ready PDF uploaded
- [ ] PMLR Publication Agreement signed by the corresponding author and uploaded (≤ 10 MB)
- [ ] ICML publication license signed (one author); oral presenters sign recording consent
