# Resolving Conflicts Between Sources

The writing sources disagree on several points. Use this table instead of picking at
random. General priority: **ICML official rules > integrity of evidence > reader
comprehension > style heuristics**. Any style rule may be broken when you can state the
reason for the rule and why this case differs; log notable deviations in `decisions.md`.

| Topic | Positions | Resolution for this skill |
|---|---|---|
| Passive voice | Perez: never. Foerster: avoid when possible. Gopen & Swan: choose voice by whose story the paragraph tells | Default active. Keep passive when it keeps the paragraph's topic in the topic position or when the actor is irrelevant (e.g., standard procedures). |
| Hedging | Perez, Lipton: drop "may"/"can". Nanda: calibrate claims, hedged claims are legitimate | First set the claim's strength level from the evidence (narrative-and-claims.md). Then express it with explicit scope or evidence words ("on 3 of 5 tasks", "suggests") and delete empty hedges. |
| Related work position | Nanda: usually penultimate. Farquhar: early or after results depending on baselines. Foerster: after the introduction | After results by default; Section 2 when the motivation depends on a gap or flaw in specific prior work. Record the choice. |
| Conclusion | Nanda, Farquhar: often unnecessary. Foerster: include a recap | Short (2–4 sentences), combined with limitations if space is tight. First thing to shrink under page pressure. |
| Future work | Foerster: possibly at end of intro if space. Farquhar: at the end, framed as limitations | At the end, framed as limitations. |
| Contribution list | Farquhar, Foerster: 2–4 bullets. Nanda: bullets of claims with evidence pointers | 2–4 bullets, each a claim plus a pointer to its evidence. |
| Using LLMs to draft | Farquhar: almost nobody should draft with LLMs. Nanda: LLM drafts can break writer's block, never paste directly | The agent drafts only after Checkpoints 1–2, drafts to be cut, applies the LLM-tell removal list, and flags its draft as requiring human rewriting of key paragraphs (abstract, intro first and last paragraphs). |
| Sentence length | Perez, Lipton: split long sentences. Gopen & Swan: length is not the problem; too many emphasis candidates is | Split when a sentence carries more than one point needing emphasis; keep long sentences that resolve cleanly. |
| Filling the page limit | Foerster: fill the page limit; whitespace looks lazy. Farquhar: do not break the style guide to squeeze text | Use the full 8 pages with legitimate means only. Never alter template spacing. |
| Citing broadly | Lipton: cite generously when relevant. Nanda: avoid performative citation | Cite everything genuinely relevant and anything a reviewer would expect; do not pad with irrelevant work. Concurrent work (< 2 months before deadline) is optional at ICML. |
| Emphasis formatting | Foerster: bold for key message, italic for key words, be consistent | Use sparingly; consistent convention throughout; never bold-to-shout in running text. |
